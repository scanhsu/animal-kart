# 動物屁屁大賽車

可愛動物 3D 賽車小遊戲，用瀏覽器就能玩（手機、平板、電腦都可以）。

- 6 隻動物：小豬、柴犬、企鵝、兔兔、熊貓、灰貓
- 道具：香蕉皮、大便飛彈、大便散彈、屁屁火箭、超級臭屁彈、陳媽媽爆氣、戳腰子、智障小孩耍皮
- 地形：草原、沙漠、泥巴水坑、冰雪滑路、加速帶、跳台

連線對戰：首頁按「建立房間」拿到 4 碼房號，朋友在首頁按「加入房間」輸入房號（或直接點邀請連結）。最多 4 個真人，加上 0～4 隻電腦對手。連線用 [PeerJS](https://peerjs.com/)（MIT 授權）直連。

操作：手機／平板按住畫面拖動轉彎（自動油門）；電腦用方向鍵開車，空白鍵用道具。

3D 引擎使用 [three.js](https://threejs.org/) r128（MIT 授權）。
